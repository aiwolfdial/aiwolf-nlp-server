# aiwolf-nlp protocol

*Structure of the packets the server sends to agents.*

## Definitions

- <a id="%24defs/Packet"></a>**`Packet`** *(object)*: Packet structure. Cannot contain additional properties.
  - <a id="%24defs/Packet/properties/request"></a>**`request`** *(required)*: Type of request. Refer to *[#/$defs/Request](#%24defs/Request)*.
  - <a id="%24defs/Packet/properties/info"></a>**`info`**: Information indicating the current state of the game. Refer to *[#/$defs/Info](#%24defs/Info)*.
  - <a id="%24defs/Packet/properties/setting"></a>**`setting`**: Game setting information. Refer to *[#/$defs/Setting](#%24defs/Setting)*.
  - <a id="%24defs/Packet/properties/talk_history"></a>**`talk_history`** *(array or null)*: History of talks.
    - <a id="%24defs/Packet/properties/talk_history/items"></a>**Items**: Refer to *[#/$defs/Talk](#%24defs/Talk)*.
  - <a id="%24defs/Packet/properties/whisper_history"></a>**`whisper_history`** *(array or null)*: History of whispers.
    - <a id="%24defs/Packet/properties/whisper_history/items"></a>**Items**: Refer to *[#/$defs/Talk](#%24defs/Talk)*.
  - <a id="%24defs/Packet/properties/new_talk"></a>**`new_talk`**: Newly broadcast talk in group chat mode. (Only for `TALK_BROADCAST` requests). Refer to *[#/$defs/Talk](#%24defs/Talk)*.
  - <a id="%24defs/Packet/properties/new_whisper"></a>**`new_whisper`**: Newly broadcast whisper in group chat mode. (Only for `WHISPER_BROADCAST` requests). Refer to *[#/$defs/Talk](#%24defs/Talk)*.
- <a id="%24defs/Info"></a>**`Info`** *(object)*: The structure that contains information about the current state of the game within the packet. Cannot contain additional properties.
  - <a id="%24defs/Info/properties/game_id"></a>**`game_id`** *(string, required)*: Game identifier.
  - <a id="%24defs/Info/properties/day"></a>**`day`** *(integer, required)*: Current day.
  - <a id="%24defs/Info/properties/agent"></a>**`agent`** *(string, required)*: The name of the agent.
  - <a id="%24defs/Info/properties/profile"></a>**`profile`** *(string)*: The agent's profile. (Only for `INITIALIZE` request). If not set, it is None.
  - <a id="%24defs/Info/properties/medium_result"></a>**`medium_result`**: The result of the medium (only if the agent's role is Medium and the result is set). Refer to *[#/$defs/Judge](#%24defs/Judge)*.
  - <a id="%24defs/Info/properties/divine_result"></a>**`divine_result`**: The result of the divination (only if the agent's role is Seer and the result is set). Refer to *[#/$defs/Judge](#%24defs/Judge)*.
  - <a id="%24defs/Info/properties/executed_agent"></a>**`executed_agent`** *(string)*: The result of the previous day's exile (only if an agent was exiled).
  - <a id="%24defs/Info/properties/attacked_agent"></a>**`attacked_agent`** *(string)*: The result of the previous night's attack (only if an agent was attacked).
  - <a id="%24defs/Info/properties/vote_list"></a>**`vote_list`** *(array)*: The results of the votes (only if vote results are public).
    - <a id="%24defs/Info/properties/vote_list/items"></a>**Items**: Refer to *[#/$defs/Vote](#%24defs/Vote)*.
  - <a id="%24defs/Info/properties/attack_vote_list"></a>**`attack_vote_list`** *(array)*: The results of the attack votes (only if the agent's role is Werewolf and the attack vote results are public).
    - <a id="%24defs/Info/properties/attack_vote_list/items"></a>**Items**: Refer to *[#/$defs/Vote](#%24defs/Vote)*.
  - <a id="%24defs/Info/properties/status_map"></a>**`status_map`** *(object, required)*: A map showing the survival status of each agent. Can contain additional properties.
    - <a id="%24defs/Info/properties/status_map/additionalProperties"></a>**Additional properties**: Refer to *[#/$defs/Status](#%24defs/Status)*.
  - <a id="%24defs/Info/properties/role_map"></a>**`role_map`** *(object, required)*: A map showing the roles of each agent (roles of agents other than oneself are not visible). Can contain additional properties.
    - <a id="%24defs/Info/properties/role_map/additionalProperties"></a>**Additional properties**: Refer to *[#/$defs/Role](#%24defs/Role)*.
  - <a id="%24defs/Info/properties/remain_count"></a>**`remain_count`** *(integer)*: The maximum number of remaining possible talk or whisper requests (only for `TALK` or `WHISPER` requests).
  - <a id="%24defs/Info/properties/remain_length"></a>**`remain_length`** *(integer)*: The maximum number of characters that can be consumed by remaining talk or whisper requests, excluding the minimum character count. If no limit, set to None.
  - <a id="%24defs/Info/properties/remain_skip"></a>**`remain_skip`** *(integer)*: The number of remaining skips allowed for talk or whisper requests (only for `TALK` or `WHISPER` requests).
- <a id="%24defs/Judge"></a>**`Judge`** *(object)*: The structure that contains the results of divinations or medium results. Cannot contain additional properties.
  - <a id="%24defs/Judge/properties/day"></a>**`day`** *(integer, required)*: The day the judgment was made.
  - <a id="%24defs/Judge/properties/agent"></a>**`agent`** *(string, required)*: The agent who made the judgment.
  - <a id="%24defs/Judge/properties/target"></a>**`target`** *(string, required)*: The agent who was judged.
  - <a id="%24defs/Judge/properties/result"></a>**`result`** *(required)*: The result of the judgment. Refer to *[#/$defs/Species](#%24defs/Species)*.
- <a id="%24defs/Vote"></a>**`Vote`** *(object)*: The structure that contains the content of a vote. Cannot contain additional properties.
  - <a id="%24defs/Vote/properties/day"></a>**`day`** *(integer, required)*: The day the vote took place.
  - <a id="%24defs/Vote/properties/agent"></a>**`agent`** *(string, required)*: The agent who cast the vote.
  - <a id="%24defs/Vote/properties/target"></a>**`target`** *(string, required)*: The agent who was voted on.
- <a id="%24defs/Talk"></a>**`Talk`** *(object)*: The structure that contains the content of the conversation. Cannot contain additional properties.
  - <a id="%24defs/Talk/properties/idx"></a>**`idx`** *(integer, required)*: Index of the conversation.
  - <a id="%24defs/Talk/properties/day"></a>**`day`** *(integer, required)*: The day the conversation took place.
  - <a id="%24defs/Talk/properties/turn"></a>**`turn`** *(integer, required)*: The turn number when the conversation took place.
  - <a id="%24defs/Talk/properties/agent"></a>**`agent`** *(string, required)*: The name of the agent who spoke.
  - <a id="%24defs/Talk/properties/text"></a>**`text`** *(string, required)*: The content of the conversation.
  - <a id="%24defs/Talk/properties/skip"></a>**`skip`** *(boolean, required)*: Whether the conversation was skipped.
  - <a id="%24defs/Talk/properties/over"></a>**`over`** *(boolean, required)*: Whether the conversation was over.
  - <a id="%24defs/Talk/properties/time"></a>**`time`** *(integer, required)*: The time the conversation took place (Unix milliseconds).
- <a id="%24defs/Setting"></a>**`Setting`** *(object)*: The structure that contains the game settings. Cannot contain additional properties.
  - <a id="%24defs/Setting/properties/agent_count"></a>**`agent_count`** *(integer, required)*: Number of players in the game.
  - <a id="%24defs/Setting/properties/max_day"></a>**`max_day`** *(integer)*: Maximum number of days in the game. If no limit, set to None.
  - <a id="%24defs/Setting/properties/role_num_map"></a>**`role_num_map`** *(object, required)*: A map showing the number of each role. Can contain additional properties.
    - <a id="%24defs/Setting/properties/role_num_map/additionalProperties"></a>**Additional properties** *(integer)*
  - <a id="%24defs/Setting/properties/vote_visibility"></a>**`vote_visibility`** *(boolean, required)*: Whether to reveal the results of the votes.
  - <a id="%24defs/Setting/properties/talk"></a>**`talk`** *(required)*: Refer to *[#/$defs/SettingTalk](#%24defs/SettingTalk)*.
  - <a id="%24defs/Setting/properties/whisper"></a>**`whisper`** *(required)*: Whisper settings. Refer to *[#/$defs/SettingTalk](#%24defs/SettingTalk)*.
  - <a id="%24defs/Setting/properties/vote"></a>**`vote`** *(required)*: Refer to *[#/$defs/SettingVote](#%24defs/SettingVote)*.
  - <a id="%24defs/Setting/properties/attack_vote"></a>**`attack_vote`** *(required)*: Refer to *[#/$defs/SettingAttackVote](#%24defs/SettingAttackVote)*.
  - <a id="%24defs/Setting/properties/timeout"></a>**`timeout`** *(required)*: Refer to *[#/$defs/SettingTimeout](#%24defs/SettingTimeout)*.
- <a id="%24defs/SettingTalk"></a>**`SettingTalk`** *(object)*: Talk settings. Cannot contain additional properties.
  - <a id="%24defs/SettingTalk/properties/max_count"></a>**`max_count`** *(required)*: Refer to *[#/$defs/SettingTalkMaxCount](#%24defs/SettingTalkMaxCount)*.
  - <a id="%24defs/SettingTalk/properties/max_length"></a>**`max_length`** *(required)*: Refer to *[#/$defs/SettingTalkMaxLength](#%24defs/SettingTalkMaxLength)*.
  - <a id="%24defs/SettingTalk/properties/duration"></a>**`duration`** *(integer)*: Total time limit for the group chat phase (in milliseconds). None if not set.
  - <a id="%24defs/SettingTalk/properties/max_skip"></a>**`max_skip`** *(integer, required)*: Maximum number of skips per agent per day.
- <a id="%24defs/SettingTalkMaxCount"></a>**`SettingTalkMaxCount`** *(object)*: Talk count settings. Cannot contain additional properties.
  - <a id="%24defs/SettingTalkMaxCount/properties/per_agent"></a>**`per_agent`** *(integer, required)*: Maximum number of speeches per agent per day.
  - <a id="%24defs/SettingTalkMaxCount/properties/per_day"></a>**`per_day`** *(integer, required)*: Maximum number of speeches for all agents per day.
- <a id="%24defs/SettingTalkMaxLength"></a>**`SettingTalkMaxLength`** *(object)*: Talk length settings. Cannot contain additional properties.
  - <a id="%24defs/SettingTalkMaxLength/properties/count_in_word"></a>**`count_in_word`** *(boolean)*: Whether to count by word count. If not set, it is None.
  - <a id="%24defs/SettingTalkMaxLength/properties/count_spaces"></a>**`count_spaces`** *(boolean)*: Whether to include spaces when counting characters. None if not set.
  - <a id="%24defs/SettingTalkMaxLength/properties/per_talk"></a>**`per_talk`** *(integer)*: Maximum number of characters per talk. If no limit, set to None.
  - <a id="%24defs/SettingTalkMaxLength/properties/mention_length"></a>**`mention_length`** *(integer)*: Additional character count when mentioning another agent in a talk. If no limit, set to None.
  - <a id="%24defs/SettingTalkMaxLength/properties/per_agent"></a>**`per_agent`** *(integer)*: Maximum number of characters per agent per day. If no limit, set to None.
  - <a id="%24defs/SettingTalkMaxLength/properties/base_length"></a>**`base_length`** *(integer)*: Minimum number of characters not included in the daily character limit per agent. If no limit, set to None.
- <a id="%24defs/SettingVote"></a>**`SettingVote`** *(object)*: Vote settings. Cannot contain additional properties.
  - <a id="%24defs/SettingVote/properties/max_count"></a>**`max_count`** *(integer, required)*: Maximum number of re-votes allowed in case of a tie for first place.
  - <a id="%24defs/SettingVote/properties/allow_self_vote"></a>**`allow_self_vote`** *(boolean, required)*: Whether self-voting is allowed.
- <a id="%24defs/SettingAttackVote"></a>**`SettingAttackVote`** *(object)*: Attack vote settings. Cannot contain additional properties.
  - <a id="%24defs/SettingAttackVote/properties/max_count"></a>**`max_count`** *(integer, required)*: Maximum number of re-votes allowed for attacks in case of a tie for first place.
  - <a id="%24defs/SettingAttackVote/properties/allow_self_vote"></a>**`allow_self_vote`** *(boolean, required)*: Whether self-voting is allowed for attacks.
  - <a id="%24defs/SettingAttackVote/properties/allow_no_target"></a>**`allow_no_target`** *(boolean, required)*: Whether to allow a day with no target for an attack.
- <a id="%24defs/SettingTimeout"></a>**`SettingTimeout`** *(object)*: Timeout settings. Cannot contain additional properties.
  - <a id="%24defs/SettingTimeout/properties/action"></a>**`action`** *(integer, required)*: Timeout duration for agent actions (in milliseconds).
  - <a id="%24defs/SettingTimeout/properties/response"></a>**`response`** *(integer, required)*: Timeout duration for agent survival checks (in milliseconds).
- <a id="%24defs/Request"></a>**`Request`** *(string)*: An enumeration representing the type of request. Must be one of: "NAME", "TALK", "WHISPER", "VOTE", "DIVINE", "GUARD", "ATTACK", "INITIALIZE", "DAILY_INITIALIZE", "DAILY_FINISH", "FINISH", "TALK_PHASE_START", "TALK_PHASE_END", "TALK_BROADCAST", "WHISPER_PHASE_START", "WHISPER_PHASE_END", or "WHISPER_BROADCAST".
- <a id="%24defs/Role"></a>**`Role`** *(string)*: An enumeration representing the role of an agent. Must be one of: "WEREWOLF", "POSSESSED", "SEER", "BODYGUARD", "VILLAGER", or "MEDIUM".
- <a id="%24defs/Species"></a>**`Species`** *(string)*: An enumeration that represents species. Must be one of: "HUMAN" or "WEREWOLF".
- <a id="%24defs/Team"></a>**`Team`** *(string)*: An enumeration representing a team. Must be one of: "VILLAGER" or "WEREWOLF".
- <a id="%24defs/Status"></a>**`Status`** *(string)*: An enumeration representing the survival status of an agent. Must be one of: "ALIVE" or "DEAD".
