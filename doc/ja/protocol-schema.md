# aiwolf-nlp protocol

*サーバがエージェントへ送信するパケットの構造.*

## Definitions

- <a id="%24defs/Packet"></a>**`Packet`** *(object)*: パケットの構造体. Cannot contain additional properties.
  - <a id="%24defs/Packet/properties/request"></a>**`request`** *(required)*: リクエストの種類. Refer to *[#/$defs/Request](#%24defs/Request)*.
  - <a id="%24defs/Packet/properties/info"></a>**`info`**: ゲームの現状態を示す情報. Refer to *[#/$defs/Info](#%24defs/Info)*.
  - <a id="%24defs/Packet/properties/setting"></a>**`setting`**: ゲームの設定情報. Refer to *[#/$defs/Setting](#%24defs/Setting)*.
  - <a id="%24defs/Packet/properties/talk_history"></a>**`talk_history`** *(array or null)*: トークの履歴を示す情報.
    - <a id="%24defs/Packet/properties/talk_history/items"></a>**Items**: Refer to *[#/$defs/Talk](#%24defs/Talk)*.
  - <a id="%24defs/Packet/properties/whisper_history"></a>**`whisper_history`** *(array or null)*: 囁きの履歴を示す情報.
    - <a id="%24defs/Packet/properties/whisper_history/items"></a>**Items**: Refer to *[#/$defs/Talk](#%24defs/Talk)*.
  - <a id="%24defs/Packet/properties/new_talk"></a>**`new_talk`**: グループチャット方式でブロードキャストされた新しいトーク. (リクエストの種類が TALK_BROADCAST の場合のみ). Refer to *[#/$defs/Talk](#%24defs/Talk)*.
  - <a id="%24defs/Packet/properties/new_whisper"></a>**`new_whisper`**: グループチャット方式でブロードキャストされた新しい囁き. (リクエストの種類が WHISPER_BROADCAST の場合のみ). Refer to *[#/$defs/Talk](#%24defs/Talk)*.
- <a id="%24defs/Info"></a>**`Info`** *(object)*: パケット内のゲームの現状態を示す情報の構造体. Cannot contain additional properties.
  - <a id="%24defs/Info/properties/game_id"></a>**`game_id`** *(string, required)*: ゲームの識別子.
  - <a id="%24defs/Info/properties/day"></a>**`day`** *(integer, required)*: 現在の日数.
  - <a id="%24defs/Info/properties/agent"></a>**`agent`** *(string, required)*: 自分のエージェントの名前.
  - <a id="%24defs/Info/properties/profile"></a>**`profile`** *(string)*: 自分のエージェントのプロフィール. (リクエストの種類が INITIALIZE の場合のみ). 設定されない場合は None.
  - <a id="%24defs/Info/properties/medium_result"></a>**`medium_result`**: 霊媒師の結果 (エージェントの役職が霊媒師であるかつ霊媒結果が設定されている場合のみ). Refer to *[#/$defs/Judge](#%24defs/Judge)*.
  - <a id="%24defs/Info/properties/divine_result"></a>**`divine_result`**: 占い師の結果 (エージェントの役職が占い師であるかつ占い結果が設定されている場合のみ). Refer to *[#/$defs/Judge](#%24defs/Judge)*.
  - <a id="%24defs/Info/properties/executed_agent"></a>**`executed_agent`** *(string)*: 昨日の追放結果 (エージェントが追放された場合のみ).
  - <a id="%24defs/Info/properties/attacked_agent"></a>**`attacked_agent`** *(string)*: 昨夜の襲撃結果 (エージェントが襲撃された場合のみ).
  - <a id="%24defs/Info/properties/vote_list"></a>**`vote_list`** *(array)*: 投票の結果 (投票結果が公開されている場合のみ).
    - <a id="%24defs/Info/properties/vote_list/items"></a>**Items**: Refer to *[#/$defs/Vote](#%24defs/Vote)*.
  - <a id="%24defs/Info/properties/attack_vote_list"></a>**`attack_vote_list`** *(array)*: 襲撃の投票結果 (エージェントの役職が人狼かつ襲撃投票結果が公開されている場合のみ).
    - <a id="%24defs/Info/properties/attack_vote_list/items"></a>**Items**: Refer to *[#/$defs/Vote](#%24defs/Vote)*.
  - <a id="%24defs/Info/properties/status_map"></a>**`status_map`** *(object, required)*: 各エージェントの生存状態を示すマップ. Can contain additional properties.
    - <a id="%24defs/Info/properties/status_map/additionalProperties"></a>**Additional properties**: Refer to *[#/$defs/Status](#%24defs/Status)*.
  - <a id="%24defs/Info/properties/role_map"></a>**`role_map`** *(object, required)*: 各エージェントの役職を示すマップ (自分以外のエージェントの役職は見えません). Can contain additional properties.
    - <a id="%24defs/Info/properties/role_map/additionalProperties"></a>**Additional properties**: Refer to *[#/$defs/Role](#%24defs/Role)*.
  - <a id="%24defs/Info/properties/remain_count"></a>**`remain_count`** *(integer)*: 残りのトークもしくは囁きリクエストを受信する可能性のある最大の回数. (リクエストの種類が TALK | WHISPER の場合のみ).
  - <a id="%24defs/Info/properties/remain_length"></a>**`remain_length`** *(integer)*: 残りのトークもしくは囁きリクエストで消費することのできる文字数. 最低文字数を除く. (リクエストの種類が TALK | WHISPER の場合のみ). 制限がない場合は None.
  - <a id="%24defs/Info/properties/remain_skip"></a>**`remain_skip`** *(integer)*: 残りのトークもしくは囁きリクエストでスキップすることのできる回数. (リクエストの種類が TALK | WHISPER の場合のみ).
- <a id="%24defs/Judge"></a>**`Judge`** *(object)*: 占い結果や霊媒結果などの判定結果を示す情報の構造体. Cannot contain additional properties.
  - <a id="%24defs/Judge/properties/day"></a>**`day`** *(integer, required)*: 判定が出た日数.
  - <a id="%24defs/Judge/properties/agent"></a>**`agent`** *(string, required)*: 判定を出したエージェントの名前.
  - <a id="%24defs/Judge/properties/target"></a>**`target`** *(string, required)*: 判定の対象となったエージェントの名前.
  - <a id="%24defs/Judge/properties/result"></a>**`result`** *(required)*: 判定結果. Refer to *[#/$defs/Species](#%24defs/Species)*.
- <a id="%24defs/Vote"></a>**`Vote`** *(object)*: 投票の内容を示す情報の構造体. Cannot contain additional properties.
  - <a id="%24defs/Vote/properties/day"></a>**`day`** *(integer, required)*: 投票が行われた日数.
  - <a id="%24defs/Vote/properties/agent"></a>**`agent`** *(string, required)*: 投票を行ったエージェントの名前.
  - <a id="%24defs/Vote/properties/target"></a>**`target`** *(string, required)*: 投票の対象となったエージェントの名前.
- <a id="%24defs/Talk"></a>**`Talk`** *(object)*: 会話の内容を示す情報の構造体. Cannot contain additional properties.
  - <a id="%24defs/Talk/properties/idx"></a>**`idx`** *(integer, required)*: 会話のインデックス.
  - <a id="%24defs/Talk/properties/day"></a>**`day`** *(integer, required)*: 会話が行われた日数.
  - <a id="%24defs/Talk/properties/turn"></a>**`turn`** *(integer, required)*: 会話が行われたターン数.
  - <a id="%24defs/Talk/properties/agent"></a>**`agent`** *(string, required)*: 会話を行ったエージェントの名前.
  - <a id="%24defs/Talk/properties/text"></a>**`text`** *(string, required)*: 会話の内容.
  - <a id="%24defs/Talk/properties/skip"></a>**`skip`** *(boolean, required)*: 会話がスキップであるかどうか.
  - <a id="%24defs/Talk/properties/over"></a>**`over`** *(boolean, required)*: 会話がオーバーであるかどうか.
  - <a id="%24defs/Talk/properties/time"></a>**`time`** *(integer, required)*: 会話が行われた時刻 (Unixミリ秒).
- <a id="%24defs/Setting"></a>**`Setting`** *(object)*: ゲームの設定を示す情報の構造体. Cannot contain additional properties.
  - <a id="%24defs/Setting/properties/agent_count"></a>**`agent_count`** *(integer, required)*: ゲームのプレイヤー数.
  - <a id="%24defs/Setting/properties/max_day"></a>**`max_day`** *(integer)*: ゲーム内の最大日数. 制限がない場合は None.
  - <a id="%24defs/Setting/properties/role_num_map"></a>**`role_num_map`** *(object, required)*: 各役職の人数を示すマップ. Can contain additional properties.
    - <a id="%24defs/Setting/properties/role_num_map/additionalProperties"></a>**Additional properties** *(integer)*
  - <a id="%24defs/Setting/properties/vote_visibility"></a>**`vote_visibility`** *(boolean, required)*: 投票の結果を公開するか.
  - <a id="%24defs/Setting/properties/talk"></a>**`talk`** *(required)*: Refer to *[#/$defs/SettingTalk](#%24defs/SettingTalk)*.
  - <a id="%24defs/Setting/properties/whisper"></a>**`whisper`** *(required)*: 囁きの設定. Refer to *[#/$defs/SettingTalk](#%24defs/SettingTalk)*.
  - <a id="%24defs/Setting/properties/vote"></a>**`vote`** *(required)*: Refer to *[#/$defs/SettingVote](#%24defs/SettingVote)*.
  - <a id="%24defs/Setting/properties/attack_vote"></a>**`attack_vote`** *(required)*: Refer to *[#/$defs/SettingAttackVote](#%24defs/SettingAttackVote)*.
  - <a id="%24defs/Setting/properties/timeout"></a>**`timeout`** *(required)*: Refer to *[#/$defs/SettingTimeout](#%24defs/SettingTimeout)*.
- <a id="%24defs/SettingTalk"></a>**`SettingTalk`** *(object)*: トークの設定. Cannot contain additional properties.
  - <a id="%24defs/SettingTalk/properties/max_count"></a>**`max_count`** *(required)*: Refer to *[#/$defs/SettingTalkMaxCount](#%24defs/SettingTalkMaxCount)*.
  - <a id="%24defs/SettingTalk/properties/max_length"></a>**`max_length`** *(required)*: Refer to *[#/$defs/SettingTalkMaxLength](#%24defs/SettingTalkMaxLength)*.
  - <a id="%24defs/SettingTalk/properties/duration"></a>**`duration`** *(integer)*: グループチャット方式のフェーズ全体の制限時間 (ミリ秒). 設定されていない場合は None.
  - <a id="%24defs/SettingTalk/properties/max_skip"></a>**`max_skip`** *(integer, required)*: 1日あたりの1エージェントの最大スキップ回数.
- <a id="%24defs/SettingTalkMaxCount"></a>**`SettingTalkMaxCount`** *(object)*: トークの回数の設定. Cannot contain additional properties.
  - <a id="%24defs/SettingTalkMaxCount/properties/per_agent"></a>**`per_agent`** *(integer, required)*: 1日あたりの1エージェントの最大発言回数.
  - <a id="%24defs/SettingTalkMaxCount/properties/per_day"></a>**`per_day`** *(integer, required)*: 1日あたりの全体の発言回数.
- <a id="%24defs/SettingTalkMaxLength"></a>**`SettingTalkMaxLength`** *(object)*: トークの文字数の設定. Cannot contain additional properties.
  - <a id="%24defs/SettingTalkMaxLength/properties/count_in_word"></a>**`count_in_word`** *(boolean)*: 単語数でカウントするか. 設定されない場合は None.
  - <a id="%24defs/SettingTalkMaxLength/properties/count_spaces"></a>**`count_spaces`** *(boolean)*: 文字数カウントの際に空白を含めてカウントするか. 設定されない場合は None.
  - <a id="%24defs/SettingTalkMaxLength/properties/per_talk"></a>**`per_talk`** *(integer)*: 1回のトークあたりの最大文字数. 制限がない場合は None.
  - <a id="%24defs/SettingTalkMaxLength/properties/mention_length"></a>**`mention_length`** *(integer)*: 1回のトークあたりのメンションを含む場合の追加文字数. 制限がない場合は None.
  - <a id="%24defs/SettingTalkMaxLength/properties/per_agent"></a>**`per_agent`** *(integer)*: 1日あたりの1エージェントの最大文字数. 制限がない場合は None.
  - <a id="%24defs/SettingTalkMaxLength/properties/base_length"></a>**`base_length`** *(integer)*: 1日あたりの1エージェントの最大文字数に含まない最低文字数. 制限がない場合は None.
- <a id="%24defs/SettingVote"></a>**`SettingVote`** *(object)*: 投票の設定. Cannot contain additional properties.
  - <a id="%24defs/SettingVote/properties/max_count"></a>**`max_count`** *(integer, required)*: 1位タイの場合の最大再投票回数.
  - <a id="%24defs/SettingVote/properties/allow_self_vote"></a>**`allow_self_vote`** *(boolean, required)*: 自己投票を許可するか.
- <a id="%24defs/SettingAttackVote"></a>**`SettingAttackVote`** *(object)*: 襲撃投票の設定. Cannot contain additional properties.
  - <a id="%24defs/SettingAttackVote/properties/max_count"></a>**`max_count`** *(integer, required)*: 1位タイの場合の最大襲撃再投票回数.
  - <a id="%24defs/SettingAttackVote/properties/allow_self_vote"></a>**`allow_self_vote`** *(boolean, required)*: 自己投票を許可するか.
  - <a id="%24defs/SettingAttackVote/properties/allow_no_target"></a>**`allow_no_target`** *(boolean, required)*: 襲撃なしの日を許可するか.
- <a id="%24defs/SettingTimeout"></a>**`SettingTimeout`** *(object)*: タイムアウトの設定. Cannot contain additional properties.
  - <a id="%24defs/SettingTimeout/properties/action"></a>**`action`** *(integer, required)*: エージェントのアクションのタイムアウト時間 (ミリ秒).
  - <a id="%24defs/SettingTimeout/properties/response"></a>**`response`** *(integer, required)*: エージェントの生存確認のタイムアウト時間 (ミリ秒).
- <a id="%24defs/Request"></a>**`Request`** *(string)*: リクエストの種類を示す列挙型. Must be one of: "NAME", "TALK", "WHISPER", "VOTE", "DIVINE", "GUARD", "ATTACK", "INITIALIZE", "DAILY_INITIALIZE", "DAILY_FINISH", "FINISH", "TALK_PHASE_START", "TALK_PHASE_END", "TALK_BROADCAST", "WHISPER_PHASE_START", "WHISPER_PHASE_END", or "WHISPER_BROADCAST".
- <a id="%24defs/Role"></a>**`Role`** *(string)*: 役職を示す列挙型. Must be one of: "WEREWOLF", "POSSESSED", "SEER", "BODYGUARD", "VILLAGER", or "MEDIUM".
- <a id="%24defs/Species"></a>**`Species`** *(string)*: 種族を示す列挙型. Must be one of: "HUMAN" or "WEREWOLF".
- <a id="%24defs/Team"></a>**`Team`** *(string)*: 陣営を示す列挙型. Must be one of: "VILLAGER" or "WEREWOLF".
- <a id="%24defs/Status"></a>**`Status`** *(string)*: エージェントの生存状態を示す列挙型. Must be one of: "ALIVE" or "DEAD".
